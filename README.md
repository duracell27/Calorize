# Журнал Калорій & Гідратації (GitHub Pages)

Веб-додаток для інтерактивного відстеження калорій, витрат енергії, балансу БЖВ та ефективної гідратації, синхронізований із вашою Google Таблицею.

## 🚀 Як розгорнути на GitHub Pages за 1 хвилину:

1. Створіть новий репозиторій на GitHub (наприклад, `calorie-tracker`).
2. Завантажте файл `index.html` у репозиторій (у гілку `main`).
3. Перейдіть у **Settings** (Налаштування репозиторію) -> вкладка **Pages**.
4. У розділі **Build and deployment** виберіть:
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)**
   - Натисніть **Save**.
5. За кілька секунд ваш сайт буде доступний за адресою:
   `https://<ваш-юзернейм>.github.io/calorie-tracker/`

## 📊 Як працює бекенд (Live Sync):
- Google Таблиця виступає базою даних.
- Додаток автоматично зчитує актуальні дані через Google Visualization API.
- Коли ви вносите записи в Google Таблицю (або повідомляєте мені в чаті), дашборд оновлює дані при відкритті або натисканні кнопки «Оновити дані».
